# Bike Sales Analysis in Excel w/ Dashboard

### Project Overview

This is a data project using an Excel dashboard to analyze bike sales with a focus on customer demographics, including location, income, education level, age, and gender. The dashboard uses pivot tables, slicers, and visualizations to highlight trends and purchasing patterns across demographic segments.

### Data Source

Sales Data: The primary dataset used for this analysis is the "bike_buyers.csv" file, containing detailed demographic information in regards to bike sales globally.

### Tools

- Excel - Data cleaning, data organizing, analysis, visualization, dashboard
